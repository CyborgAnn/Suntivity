Suntivity Designs: This file includes different folders that each contain png images we are using for our app. Below will state each folder title along with a brief description of the contents. 

Folders

Character Stages - 
This folder contains three png images for the different character stages. Each stage portraying a different overall mood of the user's character. The characters mood will either decrease (WorstHealth.png) when the user fails to complete a set amount of tasks, or increase (BestHealth.png) when the user successfully completes a set amount of tasks. The user will start out with MiddleHealth.png as their character and then their character will change according to their performance as mentioned above. This system is to encourage the user to "grow" their character and themselves by completing more tasks. The face and colors are blank so the user can customize their character therefore building a stronger bond.



App Art - 
This folder contains three png images for the app art. Including AppName.png which is the title seen on the start page. Then we also have Sunflower.png and SunflowerWithStem.png that are also used on the start page for decoration. These png's help to personalize and bring the app to life. Each png is fully colored to show off as a decoration rather than an interactable feature. 



Character Customization-
This folder contains the most png images for character customization. Through the app there is a reward system with points that are awarded each time the user successfully completes a task. Each png is a different reward the user can spend their points on. By personalizing the user's character there is motivation to keep completing tasks and buy more cosmetics. The png's are split into two groups, faces and plant pots. Each face is different and has a number after (Face#.png) that way the user has a variety of choices. The same goes for the plant pots (PlantPot#.png) the user can pick from any of the options. Each cosmetic will cost a set amount of points that the user can choose to spend. Once the png is bought and selected it will display on the user's character. This system is to further encourage the user to complete tasks in order to get rewards to spend on personalized cosmetic and prolong the duration of commitment and motivation. Overall accomplishing the tasks of growing the plant and yourself.
